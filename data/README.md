# data/

`affinity_merged/` and `affinity_pdsp/` hold per-receptor affinity tables derived from ChEMBL
(CC BY-SA 3.0, attribution and share-alike apply) and the PDSP Ki Database (terms not verified).
See `../DATA_LICENSES.md` before redistributing. Other data (atlas, validation maps, label table)
is generated locally and is gitignored.
